PR Bot

A GitHub App that runs from PR comments — type @prbot help on any pull request.

Commands

@prbot rebase Rebase onto the base branch
@prbot rerun Re-run the latest workflow for this PR
@prbot rerun failed Re-run only failed jobs
@prbot ready / draft Mark ready for review or back to draft
@prbot status Checks, reviews, and merge state

How it works

Install the GitHub App on your org or repos. PR Bot listens for issue comments on pull requests via a Cloudflare Worker — no long-lived servers, verified GitHub webhooks.

GitHub repo Setup guide Spec
Self-host with Workers, or fork and deploy your own.
